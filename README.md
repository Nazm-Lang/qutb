# qutb

**Installer and toolchain version manager for Nazm.**

*Qutb*, the Arabic name for the pole star — "the axis" everything turns around.

## Status

**Planned — nothing here yet.** It will install, update and switch Nazm toolchains (the role rustup plays for Rust). Until then, install from the release archive or the Homebrew tap.

This repository is part of [Nazm](https://github.com/Nazm-Lang/nazm), a natively compiled
programming language with specified semantics. Nazm is at 0.9.0, a public preview of the 1.0
draft for macOS on Apple Silicon, with no compatibility promise until 1.0 — see
[nazm.dev](https://nazm.dev).
